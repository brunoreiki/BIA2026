## Certainty quiz behaviours settings

This plugin simply adds a link to the settings page for the [Degrees of Certainty with student feedback (deferred)](https://moodle.org/plugins/qbehaviour_certaintywithstudentfbdeferred) plugin. This is needed because question behaviour plugins can not properly add settings page (see [the related issue MDL-68335](https://tracker.moodle.org/browse/MDL-68335)).
